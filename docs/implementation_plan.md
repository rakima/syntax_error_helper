# 構文エラー解析ツール 実装計画

## 方針

- Python標準ライブラリだけを利用し、入力コードは実行しない。
- GUI、共通モデル、共通スキャナ、言語別解析器を分離する。
- パーサーのエラー位置に加え、直前行や未閉鎖記号の開始位置を原因候補として返す。
- 推定結果は断定表現を避け、複数候補を同時に扱う。
